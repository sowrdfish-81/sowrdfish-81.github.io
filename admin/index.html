First-time setup

This site is fully static, so publishing happens straight from your browser to GitHub using a token. You do this once per browser — after that, you only need your password.

Create a token at github.com/settings/personal-access-tokens/new → give it a name (like: blog-editor) → Repository access: Only select repositories and pick your blog repo → Permissions → Repository permissions → Contents → Read and write → Generate token → copy and paste it here. The token is stored encrypted with your password, in this browser only.
